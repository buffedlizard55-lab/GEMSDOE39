The honest state of the diagnosis. We cannot inspect DrivenData's server-side validator, so we cannot prove which encoding caused the rejection message Predicted values must be in range [0, 1]. Two mechanisms are consistent with the evidence and we cannot separate them locally:

  1. A leaked sentinel. training_features.tif really does carry -3.4028234663852886e+38 as data. Any submission assembled by copying the feature grid's array without masking those cells ships values ~1038 in magnitude, which fails any range check outright. This is the mechanism we can demonstrate locally, and it is the one our writer guards against.
  2. NaN failing a numeric range test. The template itself is NaN outside, but 0 <= nan <= 1 evaluates to False in every IEEE-754 implementation, so a validator that tests the whole array rather than only the footprint would reject the template's own encoding.

The choice, and why. The all-finite file satisfies the range constraint under every reading of the check: no NaN, no sentinel, no nodata tag, min 0.0, max 1.0, all 12,279,160 cells finite (re-verified by re-reading the written file from disk). The NaN twin matches the template's encoding exactly and is shipped as a fallback in case the portal requires that encoding. Our own validator accepts both — 15/15 checks on the zeros file, 14/14 on the NaN twin — so the recommendation rests on the robustness argument above, not on a local test that distinguishes them.

validate_submission.py  …-nan.tif    ->  PASS 14/14   (nan_only_outside_footprint 7,111,787/7,111,787)

Correction of record. An earlier draft of this page asserted that sample_submission.tif stores -3.4e38 outside the footprint and carries no nodata tag. That is false — the sentinel belongs to training_features.tif, and the template is NaN outside with nodata=nan. The table above is read from the files, not from a prior claim.

Why the improvement is plausible. The instrument says the score depends on two things: dot count (ρ = −0.867 with live score across the corpus) and per-dot credit w (ρ = +0.712). The two effects are roughly balanced at this size, which is exactly what the break-even rule was designed to find.

Which submission slot to spend

This candidate beat its control in a pre-declared Wald SPRT — 9/9 cells, LLR +3.028 against an upper boundary of +2.996 — and beat the current holdout best on the one instrument checked against organizer scores. It clears the bar set in the project charter. The alternative (the SGMC-corridor tilts H40-F) was dropped by the extrapolation guard because 41–47 % of its dots sit on SGMC traces, where the surrogate is circular; shipping it would bet a slot on an instrument artefact.

The most valuable single experiment left is not a better detector. It is resolving IR-40-01: whether dots 100–200 m off a mapped trace score as duplicate traces (excluded here, and consistent with the one controlled live experiment) or as new fault geometry (which the measured profile and the organizer's own "newly mapped geometry of an existing fault system" language both support). That is a coin-flip worth 0.39–0.63 of the remaining headroom, and it cannot be settled locally.
