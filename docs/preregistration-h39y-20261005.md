# Pre-registration: H39Y candidate portfolio and one-candidate validation

**Registered:** 2026-10-05 UTC, before implementation or holdout scoring of the candidates below.  This file is immutable evidence of the plan; results belong in a separate dated report.  A Git commit of this file is the registration timestamp.

## Task and evidentiary boundaries

DrivenData's official problem description says the target is fault structures, that the public fault inventory is incomplete, and that newly identified expert-labelled faults are used for prize scoring. The public catalogue is therefore a development proxy, not the private test labels. The current official leaderboard is a separate, time-sensitive measurement; no local holdout statistic is a leaderboard score.

This cycle tests **one** preselected idea only. Candidate order is a geological/engineering prior set before evaluating these formulas, not a ranking learned from the holdout. The remaining candidates will not be scored on this holdout. If later evaluated, they require a new untouched holdout or a declared family-wise alpha allocation.

### Source checks performed before registration

- [DrivenData problem description](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/): official description of the fault target, incomplete public catalogue, scoring rounds, feature sources, metric, and GeoTIFF requirements.
- [USGS GeoDAWN data release](https://www.usgs.gov/data/geodawn-airborne-magnetic-and-radiometric-surveys-northwestern-great-basin-nevada-and) and [DOI 10.5066/P93LGLVQ](https://doi.org/10.5066/P93LGLVQ): official source for the airborne magnetic/radiometric survey; USGS identifies CC0 1.0 rights. The local ratio TIFFs are processed owner mirrors, not the raw USGS archive.
- [USGS Fact Sheet 2020-3055](https://pubs.usgs.gov/fs/2020/3055/fs20203055.pdf): describes airborne radiometry of K, Th, and U as a tool for mapping surface geology and notes that hydrothermal alteration may be associated with potassium enrichment. This supports plausibility only; it does not establish that the GeoDAWN ratios identify faults or geothermal alteration in this footprint.
- [INGENIOUS GDR submission 1391](https://gdr.openei.org/submissions/1391): publicly accessible dataset collection; its page states CC BY 4.0 and lists well/spring chemistry, volcanic features, and 2-m temperature probes. The latter archive's download is listed, but its bytes could not be retrieved from this environment during the pre-registration check.
- [USGS Great Basin structural-discontinuity study](https://www.usgs.gov/publications/structural-discontinuities-and-their-control-hydrothermal-systems-great-basin-usa): supports the general premise that fault interactions, stepovers, and terminations can matter to hydrothermal systems. It is not evidence that any H39Y detector will improve this competition's DTI.

## Frozen H39Y-01 recipe and comparator

1. **Inputs.** Read only `ThK`, `UK`, and `UTh` from the 4-band GeoDAWN extensions raster and `cond_surf` by its GeoTIFF band metadata from `training_features.tif`. Check exact CRS, affine transform, shape, and footprint before computing. `dist_known_fault_px`, all labels, and any leaderboard value are not detector inputs.
2. **Transforms.** Convert uint8 bands to float32 divided by 255. Gaussian-smooth each field with sigma 2.0 grid cells; compute row/column gradients. Within the competition footprint, independently scale each gradient magnitude by fixed quantiles 0.02 and 0.995 to [0,1]. At each cell select the ratio with the largest scaled gradient; let `R` be that magnitude and `C` the scaled `cond_surf` gradient. Let `A=abs(g_R dot g_C)/(norm(g_R)*norm(g_C)+1e-12)`, clipped to [0,1]. Set score to `sqrt(R*C)*A`; set outside-footprint values to zero. No scale, weighting, band, or threshold sweep is permitted on this holdout.
3. **Emission comparison.** Compare the candidate with the current best checked-in method, the H39-A-model gradient-boosted discriminant, using the same binary Poisson-disk emitter, 2.8-pixel minimum distance, 2-pixel known-fault exclusion, and per-tile budget equal to 24,000 times the tile's active-footprint fraction of the full footprint. Refit the H39-A-model within each holdout tile using only training positives and negatives outside the held-out component/collar set; use the checked-in model hyperparameters and one fixed, recorded random seed per tile. This yields out-of-fold baseline predictions rather than comparing a new field against a raster whose emission masked all holdout truth.
4. **Spatial units.** Partition the finite sample footprint into an 8 × 8 grid. Evaluate the 16 cells with even row and even column indices only, in row-major order; all other cells are spatial buffers, not alternate test cells. Erode each evaluation cell inward by 15 pixels. For a fold, hide each complete 8-connected catalogue component that intersects that cell plus a 15-pixel collar; do not use any pixel of those components to fit the baseline. Mask visible catalogue pixels and their 2-pixel exclusion buffer from both predictions and scoring. A fold is eligible only if the frozen local truth count is at least 50 pixels; this eligibility rule is applied before candidate scores are evaluated. If fewer than 9 eligible cells remain, report `not testable / no slot recommendation` without changing the grid or threshold.
5. **Outcome.** In each eligible cell calculate the official binary DTI for candidate and incumbent with the repository metric. A strict candidate DTI win is `1`; ties and losses are `0`. Feed one outcome per distinct tile to the sequential test. Do not use the old 3-seed × 4-quadrant pseudo-replicates or percentile-rank lift as Bernoulli trials.
6. **Sequential rule.** One candidate is tested at family alpha 0.05, beta 0.10, p0=0.50, p1=0.70. Update the log-likelihood ratio after every eligible tile and stop on the first boundary: upper `log(1/alpha)=2.995732` (accept H1), lower `log(beta)=-2.302585` (accept H0); otherwise stop at the end with `continue/inconclusive`. Never score another candidate on these outcomes. The test's error guarantees depend on the declared independent-Bernoulli/conditional-supermartingale model. Spatial separation reduces dependence but cannot prove geological independence; this limitation must appear beside any decision.
7. **Promotion gate.** The candidate can be recommended for a weekly slot only if it strictly beats the H39-A-model DTI in the predeclared sequence and the SPRT accepts H1. A non-crossing, H0, data/provenance failure, or ineligible fold means no recommendation. Even a pass is only a public-catalogue proxy result—not a promise to beat the private leaderboard—and it does not itself submit a file.

No result, candidate TIF, or submission slot has been selected by this registration. If implementation reveals that a frozen input or fold cannot be evaluated as specified, record the failure and do not silently alter the recipe after seeing scores.
